# 主实验二 v2：36 次执行方案

本次采用 3 张原网络，每张只取 r0 个体配置，k=100/160/200/240，rho=1/3/6，共36次，每次10轮，主结果取末3轮。先运行 g0-r0 的 k=100/200/240 与全部rho组成的9次试跑；技术核查通过后自动补27次，不按结果高低筛选。

## 固定规则

- 所有节点最多阅读11条，窗口2轮，不放回抽样；无阅读沿用原判断。
- 观察节点仅根据个人信息调用LLM；非观察节点用本轮阅读按作者去重，取所见最新公开表态。当前判断影响下一轮决策，不引入全局平均。
- 私人立场固定，普通节点评论公开立场可变，倡议者表达固定。初始感知0.5，反馈0。
- 选择评论后，每次抽取 Beta(1,9) 倾向，条数为1+Binomial(2,q)，截断至有效目标数量；不同原帖不放回抽取。
- 最新表态按数字轮次和轮内评论序号确定；LLM消息别名保留评论序号，避免一人多评论发生编号冲突。
- 原有网络、r0个体参数及各k的TH集合从已冻结主实验二准备包校验复用，不重新搜索位置。
- 同一网络的全部条件使用原配对随机种子。相同k的不同rho共享倡议者集合。

## 配置与入口

[配置](../configs/main2_factorial_v2.json) 明确覆盖旧基线的阅读参数，并将评论参数传入实际 RunConfig；旧配置及结果保留。

从项目根目录执行（先激活项目Python环境）：

```powershell
python -m scripts.main2_v2 --prepared runs/main2_v2_36_20261125 --prepare
python -m scripts.main2_v2 --prepared runs/main2_v2_36_20261125 --allow-api
```

入口先跑9次、逐条核查轨迹、保存试跑摘要，再补27次、核查全部36次并生成报告与4张图。并发为2次运行×8个LLM请求，不超过16个并发请求。接口沿用本地.env，密钥不写入报告。

技术核查包括实际参数、私人立场、阅读范围/上限、非观察节点本地比例、评论条数/目标、消息编号、通知数量、连续状态及公开表态/多数指标。失败不替代为零值；使用同一冻结包恢复，已有完成结果及请求缓存可复用。

## 分析与解释

每次运行末3轮均值之后，再对3张网络等权平均。提供总体热图、时间曲线、分网络热图和配对效应图。人数效应取k两端之差并跨rho平均，积极性效应取rho两端之差并跨k平均，交互为端点差的差。

仅3张固定网络且每张1组配置，报告描述性效应和网络间一致性，不计算退化的图内bootstrap区间，也不声称统计显著性。10轮不预设已经达到稳态。

多评论为固定背景规则，不另研究其因果贡献。实际评论量可以随k/rho、反馈和随机抽样变化。新版结果不与旧版混为同一批实验。

## 反代接口的显式非思考恢复入口（2026-11-25）

本批最初通过直连接口完成19次。后续经用户授权切换至1nvictus；对照测试发现，仅发送thinking=disabled不足以达到预期，增加reasoning_effort=none后，六条跨第1/5/10轮的真实请求均通过格式检查，未返回推理内容。

当前继续该冻结批次，应使用：

```powershell
python -m scripts.resume_main2_gateway --prepared runs/main2_v2_36_20261125 --approved-url https://api.1nvictus.me/v1 --allow-api
```

- 保持原有实验源码和输入的哈希校验；恢复适配代码及其快照在transport-sources中另行记录。
- 已完成结果不重写。未完成任务在首次使用此入口时，备份早期网关缓存到任务目录的quarantine子目录，只恢复首次接口切换前的直连缓存。后续有效非思考响应可以继续复用。
- 新请求额外发送reasoning_effort=none；请求和返回摘要写入nonthinking_transport.jsonl。原始runtime.json和identity.json表示初始执行阶段，实际后续接口与参数以gateway-transition和gateway-continuation记录为准。
- 返回推理内容、正的推理token用量或超过4096的输出用量时停止；连续3次接口错误也停止派发。检查发生在响应返回后，不能保证服务端生成量或费用的硬上限。
- 先完成一个恢复任务并独立核查，再继续其余任务。全部完成后自动核查36条轨迹并绘图。
- 最终报告将隔离阶段的额外调用用量单列，避免把它漏记为没有发生，也避免重复计入原始直连缓存。
