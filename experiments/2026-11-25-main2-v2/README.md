人数端点差+47.33个百分点，积极性端点差+24.39个百分点，交互对比+42.89个百分点。仅3个完整配对组，报告描述性结果，不报告置信区间或显著性检验。

## 文件组织与恢复

- `prepared_inputs.zip`：冻结输入、实验源码、原始运行配置、接口切换记录和恢复适配器快照，根目录为`main2_v2_36_20261125`。新增恢复适配器也放入快照的`source/scripts/`，没有改变原冻结实验源码。
- `full/trajectories/`：每个任务一个ZIP，含有效完整轨迹、调用日志、结果、任务身份、完成校验，以及适用的非思考传输日志和恢复记录。
- `excluded_attempts.zip`：历史中断轨迹及隔离响应，只用于追溯，不纳入有效结果。部分历史中断gzip缺少结束标记，清单已注明；36份有效轨迹均为完整文件。
- `full/usage.json`：最终运行日志内的调用统计，排除缓存复用；`full/quarantined_usage.json`另外记录被隔离阶段的请求，不包含独立诊断调用。

恢复时先检查ZIP的SHA-256与`archive_manifest.json`一致，再解压：

1. 将`prepared_inputs.zip`解压到新目录，得到`main2_v2_36_20261125/`。
2. 将每个任务ZIP解压到该目录的`runs/<ZIP文件名去掉.zip>/`。
3. 如需完整追溯，将`excluded_attempts.zip`解压到该目录根部，恢复`runs/.../quarantine`和`attempts`。
4. 使用项目依赖环境，在恢复目录的`source/`中运行以下只读核查，将末尾路径替换为恢复根目录的绝对路径：

```powershell
python -B -c "from pathlib import Path; from scripts.main2_v2 import audit_bundle; import sys; result=audit_bundle(Path(sys.argv[1])); print(result['runs_audited'])" "恢复根目录的绝对路径"
```

这一步不会调用API。应输出36。冻结代码保存在ZIP中，避免Git换行规范化影响原始字节校验。

仓库中直接展示的JSON和报告用于阅读，Git可能规范化其换行；涉及原始字节哈希的验证，以ZIP内文件和`archive_manifest.json`记录为准。

## 接口与实验解释边界

前19次完成于DeepSeek直连接口。因余额不足，经用户授权切换至1nvictus网关；发现`thinking=disabled`未表现出预期效果后，通过对照测试改为额外显式传入`reasoning_effort=none`，隔离早期不确定响应，仅保留可信直连缓存，完成剩余17次。

修复后的新请求检查返回推理内容、推理token及输出上限；网关硬输出上限仍未被证实可靠，本地检查只能在返回后发现异常，不能保证服务端生成或费用的硬上限。底层模型相同依据用户/提供方说明，未独立验证；接口切换与请求设置变化均保留记录。

不同k使用各自继承的TH集合，单张网络内不保证随人数严格单调。结论限于本次固定网络、个体配置、TH策略和10轮观察窗口。仓库没有包含API密钥、本地环境配置或私人阶段进展记录。
