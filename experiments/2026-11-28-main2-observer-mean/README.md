## 方案与结果

三张冻结网络，每张一组r0个体配置，k={100,160,200,240}与rho={1,3,6}构成36次运行，继承TH位置。私人立场固定、公开评论立场可变；每轮最多阅读11条，两轮窗口，Beta(1,9)及1+Binomial(2,q)多评论规则不变。

固定50名观察节点按个人实际阅读使用LLM更新p_hat；空阅读者沿用旧值。每轮结束后，将这50个值等权平均，分配给全部950名非观察节点，供下一轮行为决策使用。主指标仍是固定观察集合第8—10轮平均多数误判比例Qill，三网络等权汇总。

人数端点差为+53.04个百分点，积极性端点差为+28.56个百分点，交互对比为+44.67个百分点。三张网络的这三项对比均为正。仅3个完整配对组，因此仅作描述性分析，不报告置信区间或显著性结论。

最高条件k=240、rho=6的三网络平均Qill为78.44%，各网络分别为80.67%、74.00%、80.67%。两张网络超过80%，整体均值仍未达到80%覆盖目标。不同人数采用各自继承的TH集合；这些结果不能外推为普适人数阈值。

- `prepared_inputs.zip`：冻结网络、人物参数、TH名单、文本、源码、协议、原始运行配置、批次记录和传输哈希清单；解压根目录为`main2_observer_mean_20261127/`。

- `interrupted_prefixes.zip`：历史中断片段，保留原始字节，只用于追溯，不算额外完整实验；中断gzip可能没有正常结束标记。

- `results_snapshot.zip`：上述统计报告、图表和前缀核对的原始字节副本，保留`full_analysis/`与`recovery_history/`路径，供原始文件哈希复核。

恢复方法：将准备包解压到新目录，再把每个任务ZIP解压到恢复根目录的`runs/<ZIP文件名去掉.zip>/`。如需追溯中断片段，将`interrupted_prefixes.zip`解压到恢复根目录。核对ZIP及内部文件的SHA-256与归档清单一致。

在安装了项目依赖的Python环境中，进入恢复根目录的`source/`，运行：

```powershell
python -B -c "from pathlib import Path; from scripts.main2_v2 import audit_bundle; import sys; print(audit_bundle(Path(sys.argv[1]))['runs_audited'])" "恢复根目录的绝对路径"
```

此命令只做离线复核，不调用API，应输出36。使用ZIP内冻结源码，可避免Git换行规范化造成的字节哈希差异。在线JSON和Markdown供阅读；原始字节校验以ZIP成员为准。

## 运行恢复与接口限制

本批先完成19条，额度恢复后补齐17条。两条中断轨迹的原7轮、8轮前缀与最终消息、阅读、状态和决策完全一致。实际请求17,921次，排除787条缓存复用；506条额度耗尽API错误和99条非复用无效响应保留在日志中。

接口为用户本机Magpie，返回模型标识为`qoder-cn/dfmodel`；请求`reasoning_effort=none`、`temperature=0`、`max_tokens=4096`、超时180秒。含重放的18,202条返回响应全部通过非思考检查，报告推理token均为0、最大输出127 token。温度透传按官方CLI字段实现，但服务端不回显实际内部采样温度。

实际运行依赖本机Qoder插件0.2.75的非思考能力发布与温度透传补丁。恢复时发现自动升级到0.2.77，已还原本批冻结字节并固定版本。传输快照哈希保存在[transport_manifest.json](transport_manifest.json)。此公开归档不分发第三方插件实现、账号配置、额度监控或密钥；因此上述离线审计可直接复核，真实API重跑仍需自行配置兼容接口并验证请求参数。准备包中的`launch_checked.py`保留原执行方式，其中机器专用路径和未发布的插件快照不能直接在另一台机器使用。

共享平均感知可能使非观察节点集体跨过判断阈值，不能直接解释为自发局部相变。与11月25日版本同时存在感知规则及调用渠道差异，跨版本差异不能全部归因于均值广播。十轮结果不能证明长期收敛。

本次仅归档已有结果，没有重新运行实验或开展新的探索性拟合分析。
